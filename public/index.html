RESTful API Reference & Specifications

Use these routes with Postman, Insomnia, curl, or frontend frameworks.

🔐 Authentication Routes (/api/auth)

MethodEndpointAuthDescription
POST /api/auth/register Public Create a new user account (name, email, password, bio)
POST /api/auth/login Public Authenticate user & receive JWT bearer token (email, password)
GET /api/auth/me Bearer Token Fetch currently logged in user profile
PUT /api/auth/profile Bearer Token Update profile details (name, bio, avatar)
PUT /api/auth/change-password Bearer Token Change password (currentPassword, newPassword)

📝 Blog Post Routes (/api/posts)

MethodEndpointAuthDescription
GET /api/posts Public Get published posts (supports ?search=, ?category=, ?page=, ?limit=)
GET /api/posts/:idOrSlug Public Get single post by MongoDB ID or slug with comments & auto-increment views
POST /api/posts Bearer Token Create a new article (author set automatically from JWT)
PUT /api/posts/:id Author / Admin Update title, content, cover, tags, or category
DELETE /api/posts/:id Author / Admin Delete post and all attached comments
POST /api/posts/:id/like Bearer Token Toggle like / unlike on an article
GET /api/posts/user/me Bearer Token Fetch all posts written by the logged-in user

💬 Comment Routes (/api/comments)

MethodEndpointAuthDescription
POST /api/comments Bearer Token Add comment to post ({ postId, content })
GET /api/comments/post/:postId Public Retrieve all comments belonging to a specific post
DELETE /api/comments/:id Author / Admin Delete a comment by its ID
